# JackSignal para Home Assistant

Añade a Home Assistant un reproductor para la salida de audio local. Usa FFmpeg y PulseAudio para la reproducción.

[Abrir JackSignal en el Marketplace](https://my.home-assistant.io/redirect/marketplace_repository/?owner=Gente-del-Condado&repository=jacksignal-ha&category=integration)

En Home Assistant 2026.11 o posterior, abre **Ajustes → Marketplace**, añade este repositorio como **Integración** y pulsa **Instalar**. Después abre **Ajustes → Dispositivos y servicios → Añadir integración** y busca **JackSignal**.

Las aplicaciones de Home Assistant OS se distribuyen por separado en [Mis-app](https://github.com/Gente-del-Condado/Mis-app).
